# Week 3 – Package & Make It Sellable

**Goal by end of Week 3:**  
A complete product that someone can buy and use today.

---

### Day 1–2 – Packaging

**Tasks:**
- [ ] Create a clean zip structure or private GitHub repo for buyers
- [ ] Write a clear README for the buyer (how to install the skills)
- [ ] Add version number (v1.0)
- [ ] Optional: simple cover image in Canva

---

### Day 3–4 – Sales Page & Pricing

**Tasks:**
- [ ] Write sales copy (we will do this together – see `product/sales-copy.md`)
- [ ] Decide final price ($19 / $24 / $29)
- [ ] Set up the product on Gumroad (or Carrd + Stripe)
- [ ] Create a simple thank-you / delivery page

**Gumroad is recommended** because it is free until you make sales and handles delivery automatically.

---

### Day 5 – Positioning & Assets

**Tasks:**
- [ ] Write 3–4 short posts you can reuse for launch (Reddit, X, etc.)
- [ ] Prepare a short demo (text example of before/after using one skill)
- [ ] Decide the product name and one-line promise

---

### Day 6–7 – Soft Test

**Tasks:**
- [ ] Share the pack privately with 2–3 people (friends, Discord, etc.) if possible
- [ ] Fix any obvious install or clarity issues
- [ ] Make the sales page live (even if unpublished)

**End of Week 3 target:**  
Product is fully ready to sell. We only need traffic.
