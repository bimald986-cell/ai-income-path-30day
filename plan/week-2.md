# Week 2 – Build the Skills

**Goal by end of Week 2:**  
6–8 solid, tested skills ready for packaging.

---

### Daily Rhythm (repeat for each skill)

1. Write the skill using Claude Code / Cursor + ECC help
2. Test it on a real or realistic example
3. Improve based on the test
4. Commit to the repo
5. Mark it done in `product/skill-list.md`

**Target pace:** 1–1.5 skills per day (some are smaller)

---

### Recommended Build Order (easiest → harder)

1. Meeting notes → action items
2. Weekly business review
3. Scope creep / change request reply
4. Simple invoice / payment reminder draft
5. Client discovery / onboarding questions
6. Proposal outline / first draft
7. Case study / testimonial capture
8. (Optional) One extra high-value skill

---

### Quality Bar (every skill must pass)

- [ ] Clear name and one-sentence description
- [ ] Works when the user just says the trigger phrase
- [ ] Produces useful, non-generic output
- [ ] Has at least one example in the skill file
- [ ] You personally tested it at least twice

---

### End of Week 2 Checklist

- [ ] All planned skills exist in `/skills`
- [ ] Each skill has been tested
- [ ] `product/skill-list.md` is fully updated
- [ ] You feel proud of at least 4 of them

If you fall behind, we drop the weakest 1–2 skills. Shipping a strong smaller pack is better than a weak big pack.
