# Product Capability Map — AI Operations Partner v0.1

**Status:** Locked for MVP experiment on Day 4

The previous seven standalone skills are retained as useful sub-capabilities, but v0.1 is packaged and tested as one integrated product rather than a prompt bundle.

| Capability | Job to be done | MVP priority |
|---|---|---|
| Evidence-Based Work Prioritizer | Decide what deserves attention, using outcomes, delay, dependencies, risk, and evidence; explain why | P0 |
| Recurring Work Operator | Take approved repetitive work off the owner's plate and escalate exceptions | P0 |
| Market Intelligence | Monitor market/customer/competitor evidence and identify changes that matter | P0 |
| Market Validation | Compare candidate customer segments and actively test/disprove hypotheses | P0 |
| Prospect Research & Qualification | Find legitimate prospects, determine fit, and explain qualification | P0 |
| Personalized Outreach Preparation | Create evidence-based, non-spam outreach for owner approval | P0 |
| Daily Operating Brief | Explain product/market status, last-24-hour outcomes, risks, approvals, and today's plan | P0 |
| Learning & Audit Trail | Record evidence, decisions, overrides, actions, outcomes, and lessons | P0 |
| Email Triage | Read/filter/prioritize authorized email and prepare actions/replies | P1 integration |
| Content Operations | Run approved recurring production workflows such as M&M | P1 integration |
| Repository Operations | Work on approved GitHub backlog/maintenance within delegated authority | P1 integration |
| Outreach Execution | Send/follow up through authorized channels after guardrails are validated | P1 integration |

## Product promise under test

**An evidence-driven AI Operations Partner that helps a solo operator decide what matters, takes approved recurring work off their plate, watches the market, and helps create new business opportunities—while showing the evidence behind important decisions.**

This is a hypothesis. It must earn the right to become sales copy through real validation.

## Autonomy rule

**Autonomy follows consequence.**

The system can observe broadly within authorized sources, act independently inside explicit reversible guardrails, and must seek approval for consequential actions until that class of action has been deliberately delegated.

## Commercial test

The product's first assignment is to help find its own first paying customer. Success is measured by qualified conversations and paid conversion, not by number of tasks or messages generated.
